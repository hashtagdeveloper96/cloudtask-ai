# CloudTask AI

Cloud-native AI-powered task management platform.

## Project Goal

CloudTask AI is a production-style cloud-native application designed to demonstrate:

- Software development
- Cloud engineering
- DevOps
- Infrastructure as Code
- CI/CD
- Containerization
- Observability
- Security
- AI engineering

## Architecture

The platform will consist of:

- React frontend
- FastAPI backend
- PostgreSQL database
- Redis
- AI/LLM service
- Docker containers
- AWS infrastructure
- Terraform
- Ansible
- Jenkins
- Prometheus
- Grafana
